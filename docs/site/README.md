# ESPlab — many boards, one computer

ESPlab Labs is the home of a cluster OS for ESP32 boards: many boards that
behave as **one computer** — pooled CPU, pooled storage, a sandboxed task
VM — fully local over ESP-NOW. No router, no cloud.

| repo | what it is |
|---|---|
| [ESPlab](ESPlab) | the machine: firmware, VM, virtual boards, tests |
| [ESPlab-WebUI](ESPlab-WebUI) | the machine's dashboard service (console-backed) |
| [ESP-On-Demand](ESP-On-Demand) | video decoded by the whole cluster (needs WebUI) |
